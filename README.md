# CoolTech Refrigeration

Website for CoolTech Refrigeration — supplier of refrigeration equipment (ice cream and popsicle machines, milk & salad ATMs, cooler boxes, freezers, cold rooms) and provider of installation, repair and maintenance services in Kenya.

## Tech stack

- Vite
- React + TypeScript
- Tailwind CSS
- shadcn/ui

## Local development

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

Deployment notes are in `DEPLOYMENT-GUIDE.md`.
